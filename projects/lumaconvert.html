LumaConvert · 轻转

专注本地批量转换 iPhone 照片与视频：HEIC、HEIF 转 JPG，MOV、MP4 转 H.264 + AAC 的 MP4。无需上传云端，原始文件保留。

查看 GitHub 源码 ↗下载发布版本 ↗
Why I built it

从格式兼容到批量转换，减少重复操作

iPhone 产生的 HEIC 和 MOV 文件在跨设备整理时常需要转换格式；用原生桌面界面组织批处理、预览和进度，让整个过程直观可控。

项目亮点

  • Windows x64 原生界面，使用 C#、.NET 10 和 WinUI 3；支持文件与文件夹拖放、递归扫描与重复过滤。
  • 支持 HEIC / HEIF / JPG / JPEG / PNG 转 JPG，MOV / MP4 转 H.264 + AAC 的 MP4，并提供清晰优先、均衡压缩和体积优先三档。
  • 批量转换队列、缩略图、选中预览、逐文件进度、输出重名自动改名，以及任务取消与临时文件清理。
  • 媒体转换在本机完成；原文件始终保留。便携版自带所需运行库和媒体组件。

实现方式

项目把原生 UI、转换核心、独立图片解码进程与验证程序分开组织。视频转换基于 FFmpeg；通过限制视频线程与预览缓存，兼顾批量任务期间的响应体验。

当前边界

转换采用有损压缩，输出文件不一定小于原文件。HDR 视频会做 SDR 色调映射；Dolby Vision 色彩准确性尚未完成验证。暂不合并 Live Photo，也不保证保留全部原始元数据。软件源码遵循 MIT 许可，第三方媒体组件另有许可证。
