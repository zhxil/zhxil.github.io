CodexWatch

让 Codex 使用额度不再需要反复打开界面确认。专为 Windows 11 打造的轻量常驻状态工具。

查看 GitHub 源码 ↗下载发布版本 ↗
Why I built it

从信息查询到低打扰的持续感知

把使用额度转化为任务栏可见的信息，减少重复检查；重点不是展示更多数据，而是在需要时快速获得状态。

项目亮点

  • 基于 C# 和 WinUI 3 开发，提供任务栏常驻胶囊、桌面悬浮面板、圆环额度概览与深浅色主题。
  • 支持额度预警、重置提醒、手动重置机会到期提醒、免打扰和开机启动设置。
  • 从本机 Codex app-server 读取额度；今天的 Token 用量统计基于本地会话记录。

当前范围与说明

README 标注任务栏嵌入属于非官方扩展方式，当前主要适配 Windows 11 主屏水平居中任务栏；部分启动验证和服务端未知字段存在边界。
